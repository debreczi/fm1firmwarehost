FM-1 Hub

An iPhone app that installs open-source firmware on the M-VAVE FM-1 over USB, and backs up and restores what is on it.

What it does

Browse the catalogue

The app shows the open-source firmwares listed by the FM-1 Firmware Hub (thefirmwarehub.com), and keeps the list for offline use. Each card shows a picture of the firmware's screen, its maker, version, type, installs and stars, with a beta badge where it applies.

Search, sort, and filter by style: synths, grooveboxes, drums & samplers, chords, trackers, dev, ambient, vintage. Each firmware's page links to its project, source, editor, browser demo, cheat sheet and feedback channel.

Install over USB

Each firmware comes as a single .fwsc file, which the app calls a package. The app installs it over USB MIDI the same way the hub's installer and M-VAVE's updater do. If an update is interrupted, you can resume it with the same package.

A .fwsc from the Files app works too, for a release the catalogue doesn't list yet.

Go back to M-VAVE's firmware

One tap installs M-VAVE's current release from M-VAVE's own server. The app reads the version from the file, so new official releases appear without an app update. Or install the official V15, which the hub keeps as a recovery image; the app accepts only the exact published file.

Back up what's there

Because the FM-1 can't send its firmware back to the phone, a backup records which firmware is on it and keeps the package that installs it again. The app finds that package by itself, and asks you for a .fwsc only if it can't.

On Felucca-family firmwares (Felucca and those built on it, such as Melodee, X0X, Ghoulbox, Jangada, Hortator, Salt and ChoralRoot), a backup also saves your music, settings, projects and samples, in a file the Felucca editor can open. You restore firmware and music separately, and you can back up automatically before every install.

Check the history

The History tab lists every install attempt: what, when, from where (the hub, a backup, a file or M-VAVE), what the FM-1 reported before and after, and the result or error.

Safety

Installing firmware always carries some risk, and the app follows seven rules to keep it down.

  1. 1Checked before anything is written. The package's size, the name it reports and its SHA-256 (a fingerprint that changes if a single byte of the file does) must all match the catalogue, or nothing is written.
  2. 2Downloads have a size limit. Anything over 4 MB is refused or stopped, and the file must be exactly the size the catalogue states. Real packages are well under 1 MB.
  3. 3It notes what it is about to write. Before the FM-1 switches to update mode to receive firmware, the app records the exact package and what the FM-1 reported. That record is what makes an interrupted update resumable.
  4. 4Resume means that exact package. Two builds of one firmware report the same name, so Resume finds the package by its fingerprint. It never uses a different build or “whatever was installed last”.
  5. 5Done means the FM-1 said so. The app waits for the FM-1 to restart and report what it is running, and calls the install successful only if that matches.
  6. 6Every package you install is kept. Packages stay on the phone until you clear them in Settings, so any firmware you installed with the app can go back on without the internet. Each backup keeps its own copy either way.
  7. 7It tells you when it can't. A backup with no package says so, and why. If your history or backup list can't be read, the app tells you and sets the file aside instead of overwriting it.

What it can't do

  • –An install can leave the FM-1 needing a rescue. Read the hub's knowledge base first, and keep the official V15 at hand.
  • –Firmwares are not reviewed. Each is its author's work and responsibility. Neither the hub nor this app checks what a firmware does.
  • –The ROM-bootloader rescue needs a computer. That rescue (the “UBOOT1.00” USB disk) is not in the app. The OCT− rescue mode is, and works with the normal Install.
  • –Music backup is Felucca-family only. Other firmwares have their own editors and backup tools, and the app tells you when music backup isn't available.

The five tabs

The manual below refers to them by name.

  • Firmwares. The catalogue: search, filters, sort, list or grid, and a detail page for each firmware.
  • FM-1. Your synth: connect, see what it is running, back it up, check its MIDI ports, resume an unfinished update, install M-VAVE's firmware, and read the log.
  • Backups. Your backups. Open one to restore its firmware or music archive, share its files, rename or delete it. A note says if anything is missing.
  • History. Every install attempt, grouped by day, with totals at the top.
  • Settings. Install and MIDI options, storage sizes, links, and About.

What you need

  • –An iPhone with iOS 17 or later. iPad runs the app, but connecting to the FM-1 needs an iPhone.
  • –iPhone 15 or newer: a USB-C to USB-C cable into the FM-1.
  • –Older iPhones: Apple's Lightning to USB camera adapter, best the powered one.
  • –No driver. The FM-1 is a standard USB MIDI device, so there is nothing to install.
  • –Power. If the FM-1 doesn't power up from the phone, use a powered USB hub or the adapter's power input.
  • –Close other MIDI apps before installing. They keep the MIDI port busy.

The FM-1 Firmware Hub (thefirmwarehub.com), which lists the firmwares the app shows.

The short name a firmware reports, such as FM-1_904.

A file's fingerprint. It changes if a single byte of the file changes.
Update mode
The FM-1 is running its update loader, which receives new firmware. It stays in update mode until an update finishes.

1. First time

  1. 1Plug the FM-1 into the iPhone and switch it on.
  2. 2Open the app on the FM-1 tab and press Connect.
  3. 3The card shows what the FM-1 is running. If the firmware is in the catalogue, you see its name and version. If the hub doesn't have that version, the card says so and shows the raw identity, such as FM-1_904.
  4. 4Below that, the app says whether a backup of this firmware will include your projects and samples, or only the firmware.

If no FM-1 is found

The app lists the other MIDI ports it can see and asks “Is one of these your FM-1?” Some firmwares name their USB port after themselves. Tap the right one and the app remembers it. Asking writes nothing to the FM-1.

If the list is empty, check the cable, close other MIDI apps, and turn on Settings → MIDI → Ask every MIDI port.

2. Back up before you change anything

Do this before every install.

  1. 1On the FM-1 tab, press Back up the FM-1 now. Give it a name or keep the suggestion.
  2. 2The app records which firmware is on the FM-1 and looks for the package that can put it back: in the hub's catalogue, then on this phone, then in the maker's GitHub releases, then on M-VAVE's server.
  3. 3On a Felucca-family firmware, it also saves your music archive over USB: current music, settings, projects A–D, user banks, FM6 patches and sample slots.
  4. 4The app tells you what it saved, what it couldn't, and why. If the package is missing, open the backup on the Backups tab later and press Pick its .fwsc from Files. The backup completes itself.

Back up automatically

Turn on Settings → Installing → Back up before every install. If that backup fails, the install stops before anything is written.

3. Installing a firmware

  1. 1On the Firmwares tab, pick a firmware, read its detail page, and press Install.
  2. 2The app downloads the package and checks it against the catalogue.
  3. 3The progress sheet moves through six stages: Starting → Checking the package → Starting the update loader → Writing → Restarting → Done. The bar counts the FM-1's actual requests for data, so the progress it shows is real.
  4. 4The FM-1 restarts and reports its new identity. The app checks it against the package before it records the install as successful.

While it is writing, don't unplug the cable. If you can, don't let the phone go to sleep.

To install M-VAVE's own firmware

On the FM-1 tab, under Official firmware, press one of:

  • –Install the latest official. The button shows the current version, such as V16. The firmware comes straight from M-VAVE's download server.
  • –Back to V15 (recovery image). The known-good image the hub keeps for getting back to stock, accepted only as the exact published file.

To install a .fwsc you already have

On the FM-1 tab, open More and log and press Install a .fwsc from Files (last resort). Use it for a GitHub release the catalogue hasn't picked up yet, or for M-VAVE's own download. The app refuses any file that isn't for an FM-1.

4. If an update is interrupted

You can finish it.

The FM-1 stays in update mode until an update completes.

  1. 1Unplug the USB cable, plug it back in, and press Connect.
  2. 2The FM-1 tab shows an update-mode card naming the firmware that was being written.
  3. 3Press Resume. The app finds that exact package and continues the update.

To install something else instead, pick any firmware from the catalogue. That continues the update too.

If the card doesn't know which package it was

Another updater, or an older version of this app, started the update. Install any firmware from the list. It continues from the same place.

If the FM-1 doesn't come back at all

  1. 1Switch the FM-1 off and on again.
  2. 2If it still doesn't start, hold OCT− while switching it on. This starts rescue mode.
  3. 3Install again.
Got an error code? Go to Troubleshooting

notfound

No FM-1 answered.

→Plug the FM-1 in by USB, close other MIDI apps, then try again.

model

The package is for a different model than the connected device. Nothing was written.

→Check you picked a firmware for the FM-1.

noloader

The update loader (which receives the new firmware) did not appear after step 1.

→Still stuck? Hold OCT− while switching the FM-1 on, then press Install again.

stopped

The FM-1 or its update loader stopped part-way.

→Replug the USB cable and press Install again: the device stays in update mode until it is finished.

lost

The FM-1 was disconnected part-way.

→Replug the USB cable and press Install again: the device stays in update mode until it is finished.

noreturn

The firmware was sent, but the FM-1 did not come back.

→Power-cycle the FM-1 (switch it off and on). If it does not start, hold OCT− while switching it on and install again.

mismatch

The firmware was written, but the FM-1 reports a different identity than expected.

→Check the firmware's own notes; reinstall, or restore a backup.

foreign

The FM-1 is in another firmware's own update mode.

→Finish that update with its own updater.

package

A package failed its checks, or could not be saved on the phone.

→Refresh the catalogue and try again; free space if the phone is full.

badreq

The FM-1 asked for data that isn't in the package.

→Report it — the package and the device disagree.

protocol

The backup exchange with the FM-1 went wrong.

→Stop playback on the FM-1 and try again.

midi

The MIDI port could not be opened.

→Close other MIDI apps and replug.

cancelled

You stopped it.

—

If the app says your history and backup list could not be read

Your backup folders are untouched, and the lists start empty. The app keeps the unreadable file in its folder as library-unreadable-….json, named after a fingerprint of its contents. If it can't even make that copy, it writes nothing over the original until you free some space. To have the file looked at, copy it out through Files.

6. Restoring

Restore the firmware first, then the music.

  1. 1On the Backups tab, open a backup.
  2. 2Press Restore the firmware. The app checks the kept package against the fingerprint it saved, then installs it.
  3. 3If the backup has a music archive, press Restore the music archive. The FM-1 must be running a Felucca-family firmware. If it isn't, the app stops and asks you to restore the firmware first. On a different Felucca-family firmware the music still goes back, and the app tells you which firmware the archive came from.

Delete this backup removes the backup and its folder. Clearing the package cache in Settings never deletes backups.

7. Settings

Installing → Back up before every install
Backs up before each install, including your music if the firmware supports music backup. Every package that goes on the FM-1 also stays on this phone (about 0.6 MB each), so it can go back on without the internet.
MIDI → Ask every MIDI port
Normally the app only asks ports with FM-1-like names who they are. Turn this on if your firmware names its USB port after itself and the FM-1 isn't found.
MIDI → ports you marked
Port names you marked as your FM-1 are listed under MIDI. Swipe one to forget it.
Storage
Space used by the package cache and the backups, and a way to clear the cache. Clearing it deletes the packages kept from past installs, so putting those firmwares back needs the internet again; each backup keeps its own copy. Backups are never deleted here; each has its own Delete this backup button. Everything stays on the phone, nothing is sent anywhere, and there is no account.
Links
The hub, its knowledge base, the wall of creators, M-VAVE's downloads, and this app on GitHub.
About
What the app is, whose work the firmwares are, and the licence notice.

8. Where your files live

In the Files app, under On My iPhone › FM-1 Hub. You can copy anything there to iCloud Drive or a computer. Each backup is a folder in Snapshots: copy it out to keep it beyond this app.

Packages/
Downloaded .fwsc files, named id-version-sha8.fwsc, where sha8 is the first 8 characters of the file's SHA-256. Clearing the cache in Settings empties this folder.
Snapshots/<uuid>/package.fwsc
The package kept with a backup. Each backup has its own folder.
Snapshots/<uuid>/felucca-backup.json
The music archive, which also opens in the Felucca web editor.
library.json
The install history and the list of backups.

Detail · optional reading

How it works

The FM-1 can't send its firmware back over MIDI. In an update, it asks the phone for the package piece by piece (0x30 read requests against the logical image, answered with 7-bit packed data). Nothing can copy the firmware off the device, so a firmware backup is the exact package, identified by its SHA-256, which the app keeps.

Music and settings use a different protocol (F0 7D 46 4C …) that only Felucca-family firmwares offer. The app uses it when the FM-1 answers BACKUP_LIST.

Build it yourself

You need Xcode 16 or newer, an iOS 17 deployment target, and a free or paid Apple developer account to sign for a device.

  1. 1Open FM1Hub.xcodeproj.
  2. 2Select the FM1Hub target → Signing & Capabilities → pick your Team. Change the bundle identifier (com.debreczi.fm1hub) if Xcode asks.
  3. 3Plug in the iPhone, choose it as the run destination, and press Run.
  4. 4On a free account, trust the developer profile on the phone under Settings → General → VPN & Device Management.

The Simulator has no USB MIDI. The catalogue, filters, history and backups work there, but connecting to an FM-1 needs a real phone.
